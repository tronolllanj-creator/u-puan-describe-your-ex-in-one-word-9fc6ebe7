# Describe Your Ex in One Word

**Bounty:** Describe Your Ex in One Word  
**Entry Word:** `Beta`

Why it’s funny: “Beta” implies your ex was unfinished, early-stage, and only useful for catching bugs in the debug phase of the relationship—never quite ready for a production release.

## How to Run

1. Ensure Python 3 is installed.
2. Run:
```bash
python3 main.py
```

This writes to `entry.txt` the chosen word and its verdict, formatted for submission.
